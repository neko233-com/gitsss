# Express233 upload v1

First-party GitSSS action, MIT, Copyright 2026 The GitSSS Authors.
No npm dependencies. Node.js 24 built-ins stream multipart uploads to Express233's
existing version/file/publish HTTP API. The action is embedded in GitSSS and
materialized as `gitsss/express233-upload@v1`; no external action download is needed.

See [the usage guide](../../../../../../docs/operations/express233-upload.md).
