# gitsss-vet

Repository-local `go vet` analyzers maintained for gitsss.

| Analyzer   | Description                                                                 |
|------------|-----------------------------------------------------------------------------|
| Imports    | Checks for import sorting: stdlib, gitsss, then third-party packages.       |
| License    | Checks source file copyright and SPDX headers.                             |
| Migrations | Prevents forbidden dependencies in gitsss database migrations.             |
