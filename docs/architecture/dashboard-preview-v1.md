# Dashboard 事件预览 v1

近期事件流是按认证主体隔离的可再生预览，不是合规审计日志。每个 Token ID 拥有独立的有界列表；读取尚未个性化的预览时使用当前默认事件，清空或接收定向事件后才建立该主体的持久化文档。因此一个用户清空事件不会影响其他用户。

## LRU 语义

`TouchFor(viewer, event)` 按事件 ID 去重并把最新访问或更新的事件移到首位。超过配置容量时只淘汰列表末尾的最久未使用事件。空列表本身也会持久化，从而避免服务重启后把已清空的默认事件重新显示出来。

LRU 只作用于 Dashboard 预览。主服务审计使用独立 namespace、保留策略和事务清理，不会因为事件预览容量不足而删除。

## 状态保护

- SQLite document ID 是 Token ID 的完整 SHA-256，不暴露用户标识。
- 文档正文包含 viewer 与事件列表，使用主密钥和 AES-256-GCM 加密；namespace 与 document ID 作为 associated data。
- 启动会逐条验证密文、viewer 哈希、事件字段、唯一 ID 和容量上限。主密钥错误、密文篡改或非法超限状态都会阻止服务启动。
- 更新先写 SQLite，再替换内存视图；写入失败时保持原预览。清空操作仍需先写入不可由 LRU 淘汰的审计记录。

当前默认事件仍是开发期样例；后续由仓库、CI、通知和接管领域事件通过定向投影更新预览，并用真实聚合指标替换 Dashboard 示例数字。
