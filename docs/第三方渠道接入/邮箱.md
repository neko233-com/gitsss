# 邮箱登录与账号邮箱

邮箱是已有 GitSSS 账号的登录标识，使用**邮箱＋原密码**登录，不需要申请第三方 App ID／Secret。本说明不提供邮箱验证码无密码登录。

- 用户在账号设置修改主邮箱或管理邮箱别名。地址归属全局唯一，大小写不敏感，不能占用另一账号的地址。
- 如站点要求邮箱确认，配置 SMTP 并完成验证后使用；SMTP 凭据不是 OAuth Client Secret，不进入公开 Git。
- Google 已验证邮箱可作为额外别名加入，手填主邮箱保持原值。飞书／Discord 的任意字符串字段不能替代邮箱验证。
- 企业默认关闭自主注册，管理员分配账号或按既有邀请流程操作。
- 邮箱用于身份与提交归属，SSH 仍使用既有用户名、公钥与 Git remote。修改邮箱不改变仓库路径。

配置与安全边界见 [Enterprise identities](../features/enterprise-identities.md)。迁移后应分别验证原用户名／密码、邮箱／密码和已绑定第三方身份，不能只验证一个登录入口就宣称全部正常。
