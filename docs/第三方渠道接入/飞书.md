# 飞书统一登录

使用企业自建应用接入；**群机器人 Webhook 不能用于登录**，安装飞书桌面客户端也不会自动提供 App ID／Secret。

## 申请与配置

1. 打开 [飞书开发者后台](https://open.feishu.cn/app)，选择正确企业，创建企业自建应用，填写应用名称和说明。正式环境与测试环境建议使用不同应用。
2. **凭证与基础信息**中获取 App ID／App Secret。App ID 对应 GitSSS Client ID，App Secret 对应 Client Secret；不需要重新生成已有 Secret。
3. **添加应用能力 → 网页应用**，设置桌面端主页为实际 GitSSS 入口，例如 `https://git.example.com/`，保存。桌面浏览器工作流可选择新页面在浏览器中打开；暂未提供移动端时不要填写虚假的移动地址。
4. **安全设置 → 重定向 URL**，添加 GitSSS 显示的完整地址，如 `https://git.example.com/user/oauth2/feishu/callback`。这不是「事件与回调」中的事件订阅地址，也不是机器人 Webhook。
5. GitSSS 添加 OAuth2 源，名称 `feishu`，Provider **飞书**，填入 App ID／Secret 和正确的独立回调站点，启用。保持企业 OAuth 自动注册关闭。
6. **版本管理与发布 → 创建版本**，说明仅用于 GitSSS 登录；核对网页能力、所需身份信息、可用范围，保存并发布。若需企业管理员审核，审批通过才算正式可用。
7. 用可用范围内的用户，从同一 GitSSS 入口绑定原账号，再退出进行真实飞书登录。

## 最小权限

当前后端调用授权、token 交换与 `authen/v1/user_info`，使用登录用户基本身份，不读取企业通讯录、聊天记录、群、云文档或全员邮箱。无需为登录勾选批量读取通讯录、发送消息等权限；`offline_access` 是持续访问授权数据，也不是基本登录必需项。只有明确需要额外敏感字段时，才按官方接口字段权限单独评审。

基本授权的身份标识是 `open_id`，并不保证返回员工 `user_id`。GitSSS 在员工 ID 缺失时使用服务器获取的 `open_id`；已有非空员工 ID 绑定保留兼容。不要为了修复空 ID 申请整份通讯录权限，也不要以昵称或邮箱代替稳定身份标识。

飞书首次返回、尚未绑定时，默认进入「绑定到现有账号」。企业关闭注册后不展示注册 Tab 或注册表单；原用户名／邮箱与密码验证通过后绑定，之后飞书登录回到同一账号。已经登录 GitSSS 的用户也可在安全设置直接关联。

参考：[获取登录用户信息](https://open.feishu.cn/document/server-docs/authentication-management/login-state-management/get)、[网页登录](https://open.feishu.cn/document/uYjL24iN/uITO4IjLykDOy4iM5gjM)。供应方控制台可能更新，实际字段与审批提示以当前后台为准。

## 内网部署与常见错误

| 现象 | 检查 |
| --- | --- |
| 没有飞书按钮 | OAuth2 源已启用，Client ID 和 Secret 均非空；不是只配了通知 Webhook |
| redirect_uri 不匹配 | 完整回调白名单含正确协议、端口、路径、源名称与大小写，且没有尾部多余字符 |
| 能授权但回 GitSSS 丢失状态 | 开始与返回是不是同一 origin；是否从公网入口跳回内网；浏览器是否阻止 Cookie |
| 应用不可用／无权限 | 草稿是否已发布、企业是否审批、用户是否在可用范围、是否选错企业身份 |
| 页面授权成功但后端失败 | 服务器能否访问飞书 token/user-info API；Secret 是否配错；不要把浏览器登录 Cookie 当 Secret |
| 要求读取大量通讯录 | 先核对选中的是网页登录流程；当前 GitSSS 基本登录不需要这些权限 |
| 本机飞书已登录仍需扫码或确认 | 浏览器与桌面客户端会话并不等同；按官方授权页完成身份确认 |

内网回调可使用如 `http://192.168.1.10:5030/user/oauth2/feishu/callback`，前提是飞书控制台接受、用户浏览器可达、GitSSS 服务器能访问飞书 API。公网用户不应使用不可达的内网回调。公网回调另建匹配的配置，避免跨 origin 绑定。

## 验收记录模板

- 应用名称／企业、负责人、源名称、回调地址、发布版本与可用范围（不填 Secret）。
- 从已登录原账号绑定，记录 GitSSS 用户名；退出后飞书登录回到同一用户。
- 原密码、SSH、公钥、组织与仓库权限仍可用。
- 未绑定和范围外身份不得自行注册或取得权限。换绑冲突应拒绝，原身份仍有效。
