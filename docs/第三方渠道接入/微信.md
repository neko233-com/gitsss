# 微信网站扫码登录

## 申请

在 [微信开放平台](https://open.weixin.qq.com/) 注册并认证开发者主体，进入网站应用管理创建**网站应用**，按官方要求提交域名、站点信息、主体材料并完成审核。公众号、小程序、企业微信、微信支付的 AppID／Secret 不能直接替代网站应用凭据。资质、费用和域名备案要求以官方当前规则为准。

## 配置

1. 审核通过后，在网站应用中获取 AppID／AppSecret。
2. 设置应用的**授权回调域**，按微信后台要求填写域名；它与其他渠道填写完整 Redirect URI 的表单不同。禁止用公网不可访问的内网 IP 冒充合规域名。
3. GitSSS 添加 OAuth2 源，名称建议 `wechat`，Provider **微信**，填写网站应用 AppID／Secret，回调站点使用已批准的 HTTPS 域名。
4. 核对完整回调为 `https://git.example.com/user/oauth2/wechat/callback`，并启用源。点击微信登录进入官方 `/connect/qrconnect` 页面，使用 `snsapi_login` 网站扫码授权。
5. 从该 HTTPS 站点登录原 GitSSS 账号、绑定微信，再退出扫码登录，确认原用户、组织与权限。

## 避免踩坑

- 微信扫码不等于短信或邮箱登录；只配置二维码图片没有身份校验能力。
- 测试页能显示二维码，不代表网站应用审核或回调域已经正确。
- 同一自然人在不同应用的 openid 可能不同；GitSSS 以认证源＋供应方身份绑定，不依据昵称或头像合并账号。
- 不在前端、HTML、Git 或二维码 URL 中放 AppSecret；Secret 只用于服务器端交换。
- 未配置或未启用的源隐藏按钮。换绑先验证新微信身份，不能占用另一 GitSSS 账号的微信。

参考：[微信开放平台](https://open.weixin.qq.com/)。审批、扫码限制与授权回调域规则以对应网站应用后台为准。
