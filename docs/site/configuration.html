安装脚本支持以下参数，所有配置项均有合理默认值。

Shell (install.sh)

参数默认值说明
--port3000HTTP 端口
--root-urlhttp://localhost:{port}/站点根 URL
--job-instance-urlhttp://host.docker.internal:{port}Actions Runner 回调地址
--imagegitsss/gitsss:latestDocker 镜像名

管理员与内网账户邀请

管理员可在 /-/admin/users/invites 生成一次性账户邀请链接，有效期可选 1 小时至 7 天。链接只保存哈希、过期后自动失效，使用时在数据库事务内消费；账户创建失败会回滚消费。

邀请开户采用内网友好的最低 6 位密码，不强制复杂度和泄漏库检查。普通登录对账号与来源 IP 记录短期失败退避，只延迟错误响应，不设置账号永久锁定；正确密码不会因为他人猜测而被阻断。

API 文档

登录后可从导航的帮助入口打开 /api/swagger，查看 Swagger UI 和当前实例生成的 OpenAPI JSON。客户端集成应以实例文档为准，并使用 Token、OAuth2 或 Git HTTP 认证。

自定义更新检查

默认关闭。如需启用，指向公司内部更新服务器：

[cron.update_checker]
ENABLED = true
HTTP_ENDPOINT = http://updates.intranet.example/gitsss/version.json

请求超时 10 秒，响应上限 1 MiB，必须包含 latest.version 字段。
