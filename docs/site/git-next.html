Windows 安装与接管

关闭正在执行写操作的 Git / 终端，运行 MSI。组合包包含 git-next、内置 Git LFS、自有 Bash 和独立 Rust + GPUI Fast 的 Git-Terminal。机器版与用户版使用不同范围，不要混装。

仓库、Git 配置、SSH 密钥、known_hosts 与凭据存储保留。接管与回滚由保护的迁移事务负责。安装后重开终端检查：

where.exe git
git --version
git language get
git update check

git 应首先解析到 git-next，版本行包含 git-next。已运行的应用可能保留旧 PATH，需要重开。界面语言可用 git language set chinese、english 或 auto 切换。

自动更新与跨平台 LF

更新器以官方 GitHub 元数据决定版本身份，并行比较官方与镜像下载路线，校验下载字节。镜像不决定版本身份。

默认使用 LF 与规范化文本比较，避免纯换行符造成假改动。已有 .gitattributes、自定义 hooks、二进制和 LFS 规则保留，安装不改写历史。Unity / Tuanjie 文本资源可声明 text eol=lf；二进制资源不强制作为文本。

Git-Terminal

Ctrl+T 新建、Ctrl+W 关闭、Ctrl+Tab 切换。原生一体化标题栏含图标、拖动和系统窗口控制。本地支持 Bash、PowerShell、CMD，Bash 提供输入高亮、目录和分支提示。

SSH 主机管理、SFTP 与远程监控的使用、认证和验证边界见 独立终端手册及对应发布包。客户端独立安装；GitSSS 服务端的 Git、SSH、数据库和存储目录不受下载客户端影响。

Git-Terminal 0.2.0

下载 SSH / SFTP / Linux 监控终端。此组件更新保留 git-next 0.3.0 核心；已有安装使用匹配架构和 user/machine 范围的 MSI。Git 产品自动更新保持原有行为，此独立组件更新需手动安装。
