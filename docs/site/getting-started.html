快速开始

5 分钟完成 gitsss 安装和首次启动

前置条件

  • Docker — 需要 Docker Engine 和 Docker Compose v2
  • 镜像文件 — gitsss-image.tar（离线镜像包，从发布页获取）
  • 磁盘空间 — 建议至少 10 GB 可用空间
说明

安装器不会从公网拉取任何镜像，适合纯内网环境部署。

Step 1: 安装

将镜像包和安装脚本复制到目标服务器，然后执行：

Linux / macOS

./install/install.sh \
  --image-archive ./gitsss-image.tar \
  --install-dir /opt/gitsss \
  --port 3000 \
  --root-url http://git.example.internal:3000/ \
  --initial-admin-user root \
  --initial-admin-password 'change-this-password'

Windows (PowerShell)

.\install\install.ps1 `
  -ImageArchive .\gitsss-image.tar `
  -InstallDir C:\gitsss `
  -Port 3000 `
  -RootUrl http://git.example.internal:3000/ `
  -InitialAdminUser root `
  -InitialAdminPassword 'change-this-password'

安装器会自动完成以下操作：

  1. 加载 Docker 镜像
  2. 创建安装目录和日志目录
  3. 生成 .env 和 compose.yaml
  4. 配置自动启动（systemd / launchd / 计划任务）
  5. 启动 gitsss 容器

Step 2: 验证服务

# 检查健康状态
curl --fail http://localhost:3000/api/healthz

# 检查容器状态
docker ps --filter name=gitsss

浏览器访问 http://<你的IP>:3000，使用以下凭据登录：

字段值
用户名root
密码root
安全提示

首次登录后系统会强制要求修改密码。请立即设置一个强密码。

更新与卸载

更新时复用原安装目录和数据卷并重跑安装器；卸载前先执行 docker compose --project-directory INSTALL_DIR down。完整步骤见 运维指南。

Step 3: 创建第一个仓库

  1. 登录后点击右上角 + 按钮
  2. 选择 New Repository
  3. 填写仓库名称，选择可见性
  4. 点击 Create Repository

Step 4: 推送代码

# 初始化本地仓库
git init
git add .
git commit -m "initial commit"

# 添加远程（使用 HTTP）
git remote add origin http://git.example.internal:3000/root/my-project.git
git push -u origin main

Step 5: 配置 SSH 访问（可选）

SSH 默认端口为 2222。在 Web 界面的 Settings → SSH Keys 中添加公钥后：

# SSH 克隆
git clone ssh://git@git.example.internal:2222/root/my-project.git

# 或配置 ~/.ssh/config 简化
Host gitsss
  HostName git.example.internal
  Port 2222
  User git
