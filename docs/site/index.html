gitsss 文档

面向研发团队内网的自维护 Git 协作平台

快速开始

默认端口 5030，管理员账号 root，密码 root（首次登录强制修改）。查看 安装指南。

什么是 gitsss

gitsss 面向公司内网场景深度定制。完全离线运行，不依赖外部服务；Git、Git LFS、项目、自动化和 API 使用统一产品入口。

🔒

完全离线

服务端 + Actions Runner + Node.js + Go + Git LFS + Docker 打包在一个镜像中，无需公网

🔀

Git 兼容

仓库、组织、Issue、PR、任务看板、Packages、Release、Actions、API 保持成熟 Git 平台语义；仓库页使用可折叠侧栏统一承载全部入口，窄屏自动切换为可关闭抽屉

📢

飞书通知

内置飞书签名通知 + 自定义通知模板，适合企业内部协作

✅

GitLab 增强

Approval Rules、Protected Branches、Scoped Labels、CODEOWNERS、Artifacts

⚡

离线 Actions

内置 checkout、cache、setup-node、setup-go 等常用 Action，未知 Action 明确失败

🖥

跨平台

linux/amd64、linux/arm64、macOS arm64（Mac mini M4）、Windows

默认配置一览

配置项默认值说明
HTTP 端口5030Web 界面和 API
SSH 端口2222Git SSH 协议
管理员账号root首次登录强制修改密码
管理员密码root可通过安装器参数覆盖
最小密码长度4全站密码策略
Docker 镜像gitsss/gitsss:latest单一镜像包含全部组件
数据卷gitsss-data持久化存储

安装方式

选择你的平台，一条命令完成安装：

Linux / macOS

./install/install.sh \
  --image-archive ./gitsss-image.tar \
  --install-dir /opt/gitsss \
  --port 5030 \
  --root-url http://git.example.internal:5030/

Windows (PowerShell)

.\install\install.ps1 `
  -ImageArchive .\gitsss-image.tar `
  -InstallDir C:\gitsss `
  -Port 5030 `
  -RootUrl http://git.example.internal:5030/
